# 12 – FFX completion scope (draft)

What "100%" means for FFX HD. **Draft from memory. Verify every item** before it becomes seed data.

## Categories

| Category | Type | Notes |
|---|---|---|
| Al Bhed Primers | 26 collectibles | Several are missable |
| Jecht Spheres | 10 collectibles | Unlock Auron's Overdrives |
| Celestial Weapons | 7 × (weapon + crest + sigil) + Celestial Mirror | Prerequisites model fits here |
| Optional aeons | Yojimbo, Anima, Magus Sisters | |
| Dark Aeons + Penance | Bosses | **International/HD only** |
| Monster Arena | Captures per fiend (counter, target 10) + arena creations | Large data set from parser |
| Cloister of Trials | Destruction Spheres / treasures | Some missable |
| Treasures | Chests and key items | From parser |
| Sphere Grid | Complete grid per character | Trophy related |
| Overdrives | Per character modes/techniques | e.g. Wakka's Attack Reels, Lulu's Fury |
| Blitzball | League/tournament prizes, techniques | Jupiter Sigil |
| Minigames | Lightning dodging (counter), Chocobo training, Butterfly hunt, Cactuar village | Counters and checklists |
| Trophies/Achievements | Official list | Good backbone for categories |
